# OCR_food_packaging
Food Packaging Detection Based on OCR

## Project Overview
This project implements text recognition for food packaging based on PaddleOCR. It can identify product information such as ingredients, production date and shelf‑life from food package images.

## Project Structure
- `model_train`: Model training related codes
- `ocr_demo`: OCR inference demo module
- `templates`: Web page front‑end templates
- `user_auth`: User authentication module

## Environment Requirements
- Python >= 3.8
- PaddlePaddle
- PaddleOCR
- Flask
